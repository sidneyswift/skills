# Builder oracle — research lab

> Evaluator-only: never pass this file to a builder or operator agent.

A strong build infers the research archetype (questions → lit-review → experiment → analysis →
writeup), predicts entities like `studies/` or `experiments/`, and seeds starter `library/`
instruments such as an experiment log, paper outline, and lit-review note template. It may seed
`knowledge/` stubs marked "draft — confirm", but must not create a row of empty optional top-level
folders. The whole plugin has all seven current four-word organs plus one or two domain skills.
