# Project Overview

This repository contains portable AI agent skills. Each top-level skill directory owns its
`SKILL.md` and any references, templates, scripts, or evaluation fixtures needed to apply and verify
that skill.

## Repository structure

- `/README.md`: Installation instructions and the public skill index.
- `/project-overview.md`: Architecture map and durable additions log for contributors and agents.
- `/packages/`: Versioned distributable skill archives.
- `/docs/superpowers/specs/`: Approved design documents written before multi-file implementation work.
- `/{skill}/SKILL.md`: The discoverable entry point for one skill.
- `/{skill}/references/`: Detailed guidance loaded only when the skill needs it.
- `/{skill}/assets/`: Templates or other files generated by the skill.
- `/{skill}/evals/`: Behavioral scenarios, validators, rubrics, and improvement records.

## Skills

- `/design-inspiration/`: Mines curated design references to break creative blocks.
- `/ecosystem-mapping/`: Maps surrounding friction into a reinforcing product ecosystem.
- `/finding-unknowns/`: Surfaces requirement gaps before implementation.
- `/gauntlet-loop/`: Runs repeated build-and-critique quality loops.
- `/graph-max/`: Converts drawn workflow graphs into multi-agent scripts.
- `/handoff-spec/`: Produces a stateless-successor handoff document combining a stable goal/spec with a point-in-time status snapshot.
- `/problem-mining/`: Discovers valuable problems through structured interviews.
- `/workspace-os/`: Builds self-managing, self-improving workspaces for any domain.

## Workspace OS design and implementation

- `/docs/superpowers/specs/2026-07-28-workspace-os-work-continuity-design.md`: Defines a thin,
  evidence-gated work-package lifecycle for cross-session and cross-agent continuity in Workspace OS.
- `/docs/superpowers/plans/2026-07-28-workspace-os-work-continuity.md`: Implements and verifies that
  lifecycle through a RED baseline, focused templates, package-aware maintenance organs, and
  fresh-context handoff evals.
- `/packages/workspace-os-v0.12.0.zip`: Distributable Workspace OS skill with managed-work continuity.

## Workspace OS work-continuity evaluation

- `/workspace-os/evals/scenarios/work-continuity/builder-prompt.md`: Agent-visible consulting OS
  kickoff that does not reveal the desired work-management structure.
- `/workspace-os/evals/scenarios/work-continuity/session-start.md`: Starts cross-session internal
  agent-memory R&D.
- `/workspace-os/evals/scenarios/work-continuity/session-resume.md`: Tests takeover by a fresh agent
  with no prior chat.
- `/workspace-os/evals/scenarios/work-continuity/session-discovery.md`: Introduces evidence that must
  change the current plan.
- `/workspace-os/evals/scenarios/work-continuity/session-close.md`: Tests evidence-gated closure and
  durable-value extraction.
- `/workspace-os/evals/scenarios/work-continuity/no-package.md`: Confirms trivial same-turn work does
  not create process ceremony.
- `/workspace-os/evals/scenarios/work-continuity/oracle.md`: Hidden evaluator expectations for every
  work-continuity turn.
- `/workspace-os/evals/scenarios/research-lab/builder-oracle.md`: Hidden expectations for the sparse
  research build.
- `/workspace-os/evals/scenarios/research-lab/use-oracle.md`: Hidden expectations for research
  workspace operation.
- `/workspace-os/evals/scenarios/consulting-firm/builder-oracle.md`: Hidden expectations for the rich
  consulting build.
- `/workspace-os/evals/scenarios/consulting-firm/use-oracle.md`: Hidden expectations for consulting
  workspace operation.
- `/workspace-os/evals/baselines/v0.11.1-work-continuity.md`: Frozen RED evidence showing successful
  ad hoc handoffs but inconsistent, non-portable work topology.
- `/workspace-os/evals/test_work_continuity.py`: Standard-library RED/GREEN contract and mutation
  tests for generated work management.

## Workspace OS work-continuity templates

- `/workspace-os/assets/work-AGENTS.md.tmpl`: Shared agent lifecycle contract for managed work.
- `/workspace-os/assets/work-README.md.tmpl`: Human navigation and derived active/archive views.
- `/workspace-os/assets/work-package-README.md.tmpl`: Canonical coordination and handoff record.
- `/workspace-os/assets/work-plan.md.tmpl`: Optional detailed decomposition without copied status.
- `/workspace-os/assets/process-input-SKILL.md.tmpl`: Repeatable intake organ that reconciles package,
  domain, external, and compounding state.
